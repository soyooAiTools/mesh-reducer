# 骨骼驱动重拓扑：方法沉淀（截至 2026-11-19，范海辛第五版）

`core/skelretopo.py` 经过美术 5 次反馈、9 轮迭代之后的定稿做法。HANDOFF 2e 是逐轮的流水账（为什么改、每轮的数字）。这里只写**现在该怎么做、为什么这样做、哪些做法被美术否决过**。改这部分代码之前先读这份。

## 0. 适用范围

- **适用的源模型**：全三角面的高模，带 Max Biped 之类的蒙皮骨架，人形，例如范海辛。
- **交付**：
  - 一个新搭的低模笼子：全四边面为主，封闭流形，法线朝外。
  - 烘焙 BC/N/AO（2048）。
  - 原骨架（166 根）和传过来的权重：每顶点 ≤4 影响，100% 蒙皮。
  - 武器拆成单独的 FBX，仍挂在原手部骨骼上。
- **面数目标**：美术手工低模的 +10–15%。范海辛：角色 2612 / 2305，斧 498 / 432，弩 440 / 342。
- **原则不变**：`core/character.py` 的“删环线”原则不受影响。吉尔基线必须保持 1499 / 1309 / 0.8099% / 0 / 99/99 / 148。

## 1. 美术的红线（被否决过的做法，不要再用）

| 被否决的做法 | 美术的话 / 原因 | 现在的做法 |
|---|---|---|
| 在原模型布线上删环线、Decimate | 破面、面数是手工的 10 倍 | 按骨骼重搭笼子 |
| 硬表面（帽檐、臂甲、武器）用双层不相连的面片 + alpha | Max 视口不显示 alpha；两层是假的 | 封闭实体：环带、浮雕实体、鳍 |
| 武器用方盒条 + 平片 | 形状和高模差太远 | 浮雕实体（拉伸轮廓）+ 弩臂扫掠条带 |
| 武器内部的三角扇、碎三角 | 布线乱 | 轮廓整圈拉伸成板，两面做约束 Delaunay 后拼四边面；没有扇 |
| 武器上的钩、尖刺只放在 alpha 里 | “硬表面武器不能靠 alpha” | 主要的钩和尖进几何；只有细羽刺留在贴图里 |
| 手指是插在手上的独立管子 | 不像手 | 手指从手掌笼子的四边面长出来，和手掌是一个网格 |
| 手指截面 4→6 边过渡、截面用手指自己的 PCA 坐标系 | “手指旋转了” | 4 边截面，坐标系取自它长出来的那个手掌四边面，4 条棱从手掌直通指尖 |
| 头发分层、独立的头发壳 | 穿插、不像 | 头发是头部体积的一部分，用台阶加一片“舌头”盖在披风上 |
| 头发烘进披风、被披风盖住 | “头发应延伸在披风之上” | 头发面不进披风的烘焙源，舌头在披风外面 |
| 披风上端短一截，或上沿有一道横线 | 会被看出来 | 披风向上延伸到头发台阶下面 |
| 臂甲是穿进手臂的独立实体 | 穿插 | 臂甲和前臂一体，按真实轮廓做 |
| 箭匣穿进外套 | 穿插 | 先整体挪出，再把内侧顶点贴到外套表面 |
| 靴子：踝前硬折、鞋头是带台阶的方盒 | “鞋子变形严重” | 绕脚背的环扇形；鞋头连续收小 |

**总结成三条**：
1. 硬表面一律做封闭实体，法线朝外，不靠 alpha 表达形状。
2. 布线要像手工件：沿形体走条带，不要扇形和碎三角。
3. 部件之间不许穿插，交界处要连续，不能有折痕或台阶。

## 2. 各部位的做法（定稿）

参数都是 `core/skelretopo.py` 顶部的常量，大多可以用环境变量 `SR_*` 临时覆盖（见第 5 节）。长度单位 H = 身高，D = 武器对角线。

### 2.1 身体笼子
- **找骨链**：`analyse_skeleton` 找镜像面和成对骨链，用 `tubeness` 区分肢体和布料骨链。
- **扫环**：沿骨链扫环。每个环在环平面里取径向外轮廓；肘、膝各 3 环；躯干是水平环，一直通到头顶。
- **焊接**：手臂接在躯干侧面挖出的 2×2 洞上；腿接在躯干最下面一环。整个身体是一个封闭的四边面流形。
- **预算档位**：`BODY_TIERS`，用二分找能放下的最密一档。

### 2.2 手和手指
- **手指数量**：每只手 5 根手指（`RODS = True`），不合并。
- **接到手掌**：`attach_rods` 先算每根手指最想要哪个手掌四边面（代价是四边面到手指轴线的横向距离）。几根手指抢同一个面时，把这个面沿手指排列方向切开，每指一格。
- **截面**：`FINGER_SIDES = 4`，`_rod_profile` 的 `ring_al` 让每个环的第 i 个角对应手掌四边面的第 i 个角，所以手指不会扭。截面按 `FINGER_SHRINK` 逐环收小，最后收成爪尖。
- **保险**：每根手指建完做一次射线奇偶检查 `_parity_bad`，再对整个 body 做一次。有面朝里的手指撤回，只留在烘焙里。
- **已知不足**：手指是直的、偏细，没有跟着指节弯。

### 2.3 臂甲（贴着前臂的板）
- **先量形状**：先确认它是“贴着的板”还是“立着的鳍”，看板法线和笼子法线的夹角。
- **贴着的板（`plate_fin`）**：在板自己的平面里栅格化，取外轮廓，Douglas-Peucker 留约 10 个点，尖刺和凹口都在真实位置上。挖掉板下面那块笼子四边面，从边界环到轮廓环拉一圈面，仍是身体这一个封闭网格。
- **立着的鳍**：走帐篷脊的做法。
- **建不出来时**：`spike_fin` 是后备。所有鳍建完都过一遍奇偶检查，不过关的整片撤回。

### 2.4 头发和披风（范海辛这类：长发盖在披风上）
- **台阶**：头发在 `z_att` 以上算头部体积（`HAIR_STEP`）。紧接着往下的环拟合时不含头发，两环之间形成一个台阶。
  - 台阶高度取背面头发样本的分位数：只有“披风顶在肩部、要延伸到领口”的模型（`sk.cape_to_collar`）用 `HAIR_PCT = 45`，其余用 `HAIR_PCT0 = 12`。
  - 正面没有头发的列，两环焊成一环。背面没有头发的模型不做台阶。
- **舌头**：`add_hair_flap` 把台阶底面换成一片垂下来的舌头。
  - 外侧贴着头发表面，内侧离身体和披风至少 0.004H。
  - 最多 4 行，底边取各列头发的 2% 分位。
  - 外侧每升高 1 最多收进 0.7（`slope`），这样不会形成一道横着的檐。
  - 头发列必须是绕背面连续的一段，到袖洞列为止。
  - 舌头和身体共用顶点，是同一个封闭流形；权重从头发骨骼传过来。
- **披风**：
  - 向上延伸到台阶下 `HAIR_CAPE_TOP = 0.026H`。再高的话，披风顶点会钻进头发体积。
  - 延伸区不包含头发面，所以披风贴图里没有头发。
- **已知不足**：
  - 舌头比高模的发梢短约 0.015H。
  - 发丝之间的空隙烘到的是领子的颜色（body 组没有 alpha）。

### 2.5 披风、外套、裙摆（大而薄的布料，`build_arc`）
- **网格**：绕躯干竖直轴的弧形网格。行和列放在形状变化最大的地方。高模有里层时做成双层薄壳，内层有自己的边缘顶点和一圈侧壁。
- **自检**：建完做一次射线奇偶检查。
  - 延伸到领口的那段有问题，就不延伸、重建。
  - 两层仍有面互穿，就把网格放粗（×0.75，最多两次；没有改善就保留原网格）。
  - 艾丽丝的短裙和挎包带就是靠这一步修好的。

### 2.6 帽檐（`build_band`）和羽毛（`build_ribbon`）
- **帽檐**：绕身体轴一圈的环带，每个角度取内缘、中、外缘 3 个点，上下两面共用内外缘，封闭。
  - 中间一排顶点的厚度方向沿“实际建出来的带子”的法线。
  - 翘角处扭得厉害的四边面，显式切成两个三角面，对角线取上下两面不相交的那条。
- **羽毛**：沿中心线分段的三角截面封闭条。

### 2.7 箭匣、背包（紧凑的挂件）
- 用浮雕实体做。
- 先整体沿最深穿插处的法线挪出来（最多 0.04H），再把朝外套那一侧的顶点沿板的薄轴逐个贴到表面上（离表面 0.0015H）。
- 前后两侧的顶点按“板平面里的同一位置”配对。不要按 PCA 符号分侧，在箭尖那头会分错。

### 2.8 靴子（脚踩在地上，`BOOT`）
- **找关键点**：`_boot_plan` 在侧面轮廓上找脚背折点和鞋跟最低后点。
- **环扇形**：环绕折点外 `BOOT_PIVOT = 0.035H` 的横轴排成扇形，依次是：
  1. 靴筒环；
  2. 鞋跟环；
  3. 竖直切片 `BOOT_SLICES = [0.3, 0.6, 0.8, 0.92]`；
  4. 鞋头前面再加一个贴地的小环 `BOOT_NOSE`。
  - 轴不能太近：0.014H 时三条环挤在折点上，踝前出现硬折。
- **鞋头**：至少是前一个切片的 `BOOT_TOE = (0.82, 0.86)` 宽和高，两侧顶点后移。鞋头在宽和高上都连续收小，不能有台阶。
- **取点和鞋底**：环顶点用 `support_ring`（保留鞋底的两条棱和鞋跟的角）。离地 0.009H 以内的顶点压到地面，各切片最低的几个顶点取同一高度，鞋底是平的。
- **退回旧扫法**：脚很短或扇形自己折叠时，退回沿骨骼方向扫。
- **已知不足**：
  - 没有鞋跟凹口。
  - 布线是绕脚的环，不是手工件那种沿脚长方向铺的排。
  - 鞋头侧面贴地处有一道小折痕。

### 2.9 武器（`build_prop`）
- **拆分**：按连通块拆开。细长、圆截面的块（斧柄、箭、弦）做 N 边棱柱，中心线平滑，半径取 3 片中值。其余的做浮雕实体。
- **浮雕实体**：`relief_solid(plate=True)`，沿最薄的轴从两面打射线，得到轮廓掩膜和深度。
  1. **闭运算**：大件、粗容差时闭运算半径约 1.5 倍容差（`CLOSE_K`），把细缝先填上，被填的部分靠 alpha 剪出来。去毛刺用小半径（`spur_close`）。
  2. **平滑**：选点前先平滑轮廓（`SMOOTH_K`）。夹角小于 `SMOOTH_TIP` 的尖角和对称轴上的点不平滑。
  3. **选点**：Douglas-Peucker 按重要度取点。远离对称轴那一半的点 ×`END_BOOST`；轮廓急转弯处在预算够细时 ×1.5。
  4. **尖点合并**：尖角（齿尖、刺尖）和刀口处，前后合成一个顶点。两个合并顶点之间的内部边要恢复成两个顶点，否则是非流形。
  5. **内部点**：只在明显更厚的地方加内部点，最多 3 个。
- **弩臂**（`LIMB_STRIP = 7`）：镜像件里从弩身伸出去的最大块，按图形内部的测地距离从根部扫到钩尖。
  - 只取这些轮廓点：等距横档的两端、末端加密的两档、钩尖、翼尖（不平滑）。
  - 成对点之间的约束三角剖分，拼出来就是一条沿弧线的四边面条带。
  - 弩身至少留 11 个轮廓点；横档太多时弩身没点了，会出翻转面。
- **已知不足**：
  - 结果对预算很敏感，换预算就要重新看图。
  - 弩臂末端是短钩，不是完整的卷。
  - 斧的涡卷是方的小凸块。

### 2.10 烘焙、UV、权重
- **UV**：按管、片、端盖切缝后 unwrap，再用 `retopo.atlas` 排图集。
- **烘焙**：每个组单独烘，只看自己的高模面。射线没打到的纹素写进 BC 的 alpha，只用在布料破口上。
- **权重**：每个组单独传，否则腿会拿到裙摆的权重。`_fill_unskinned` 把没有权重的顶点补成最近有权重顶点的权重。

## 3. 质量闸门（每轮都要过，缺一不可）

```bash
PY=/path/to/python3 dev/skelretopo_round.sh 范海辛.FBX OUT 'character:1400+760,axe:530,crossbow:448' manual_vh/manual.json
python3 dev/bench.py 1500           # 吉尔基线：1499 / 1309 / 0.8099% / 0 / 99/99 / 148，必须逐位一致
# 其他人形：02 alucard、07 里奥、09 女主、10 艾丽丝、13 宇航员、16 弗朗哥，用 skelretopo_vh.py 逐个跑
```

1. **check**（`dev/skelretopo_check.py`）：三个部件都是 OK。翻转面、自相交、双面重叠、开放边、退化、游离、头发独立壳都是 0；披风和箭匣的穿插接近 0。
2. **verify**（`dev/retopo_verify.py`）：三个部件 PASS。166 根骨骼、≤4 影响、100% 蒙皮、贴图都能找到。
3. **对比数字**（`dev/skelretopo_cmp.py`）：三角面数、四边面比例、轮廓差（平面、侧面、端面）。和上一轮比，**不许变差**；变差的话写清楚变差多少、为什么。
4. **其他人形**：三角面数和自相交数和上一轮对比。数字有变化的模型必须看图，找到原因。
5. **亲自看图**（见下面的看图清单）。只有数字过关不算完成。

**看图清单**（`cmp/key*.jpg`，三列依次是手工版、本工具、高模）：
- `key9_fingers`：手指不扭，和手掌是一体的，握拳姿势正常。
- `key9_hair`：背面、侧面、3/4 视图里头发盖在披风上，没有横线和檐，披风到头发下面。
- `key9_crossbow`：弩臂是平滑的弧线条带，末端有钩、翼尖是尖的，线框里没有大的碎三角。
- `key9_boots`：侧面看踝前没有折、鞋头没有台阶；正面看鞋头宽度接近高模；鞋底平。
- `key_hand_bracer`、`key_weapons`、`key_char_closeups`、`key_pose`：看臂甲、斧、帽子、披风、箭匣和姿势有没有退步。

## 4. 迭代和交付流程

1. **读反馈**：美术的反馈在金山文档里。**页面是虚拟滚动的**，`get_page_text` 只返回屏幕上渲染出来的那部分，必须把 `.otl-scroll-container` 一段段往下滚，每次都收集文字和截图，直到文档末尾和留言区。漏看过第 3、4 条，用户为此指出过。截图存到 `WS/feedbackN/`。
2. **逐条改**：每条反馈都要改到；已知问题不要拖到下一轮。改不了的写进说明，说清楚原因。
3. **代码备份**：每轮开始和结束各备份一份 `core/skelretopo.py`，存成 `skelretopo_roundX_start.py` 和 `skelretopo_roundX_final.py`。输出放进新目录，不覆盖上一轮。
4. **过闸门**（第 3 节），然后亲自看 key 图。数字好但看图不好的，再改一轮。
5. **打包**：放到 `~/Downloads/范海辛_骨骼重拓扑_vN/`，内容如下：
   - 3 个 FBX 和 9 张 PNG（BC、N、AO）；
   - `previews/`；
   - `对比_手工版/`：放 `cmp/j/*.jpg` 和 `key*.jpg`；
   - `说明.txt`（中文）：这次按哪几条反馈改了什么、自动检查结果、面数和手工版的对比、“仍未完全解决”的清单、是否在 Max/Unity 实测过。
   - 用 `ditto -c -k --keepParent` 压缩到 Dropbox，再用 `zipfile.testzip()` 校验。
6. **HANDOFF**：在 2e 下面加一节，写改动、前后数字、还差的地方、哪些图看过、哪些没看。

## 5. 调参开关

| 常量 / 环境变量 | 默认 | 作用 |
|---|---|---|
| `SR_CLOSE_K` | 1.5 | 武器粗轮廓的闭运算半径，单位是容差 |
| `SR_SMOOTH_K` / `SR_SMOOTH_TIP` | 0.8 / 80° | 轮廓平滑强度 / 不平滑的尖角阈值 |
| `SR_END_BOOST` / `SR_END_FROM` | 1.5 / 0.5 | 弩臂末端轮廓点的加权 / 从哪里算起 |
| `SR_LIMB_STRIP` / `SR_LIMB_OTHER` | 7 / 0.45 | 弩臂扫掠的横档数（0 = 关）/ 弩臂上其余轮廓点的权重 |
| `SR_HAIR_PCT` / `HAIR_PCT0` | 45 / 12 | 头发台阶高度的分位数（延伸到领口的披风 / 其他模型） |
| `SR_HAIR_CAPE_TOP` | 0.026 | 披风顶到头发台阶下面的距离（H） |
| `SR_BOOT` | 1 | 靴子环扇形（0 = 退回沿骨骼扫） |
| `SR_BOOT_PIVOT`、`BOOT_SLICES`、`BOOT_TOE`、`BOOT_NOSE` | 见代码 | 扇形轴位置、脚上的切片、鞋头大小、鞋头前的小环 |
| `FINGER_SIDES` / `FINGER_SHRINK` | 4 / (0.92, 0.86, 0.74) | 手指截面边数 / 逐环收小 |
| `SR_DBG=1`、`SR_DUMP=目录` | | 调试日志，导出鳍和武器的栅格（不影响结果） |

## 6. 还没解决的问题（下一步）

- **弩**：弩臂末端做成完整的卷（需要多于 440 面，或者换一种做法）；小羽刺和弩身的涡卷进几何。
- **斧**：涡卷做成圆的。
- **靴子**：鞋跟凹口；布线改成沿脚长方向铺的排。
- **手指**：跟着指节弯，粗细接近高模。
- **头发**：舌头的底边跟发梢走，发丝之间透明。
- **没测过**：没有在 3ds Max 或 Unity 里实测过（权重、动画、alpha 材质）。
- **其他人形**：除艾丽丝外没有逐个看过图。各轮里奥的面数变化（986 → 938 → 1054）没有查原因。
